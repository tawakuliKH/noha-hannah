# Assets

## Brand assets
The supplied `Noha & Hannah ivory serif monogram(4).png` is the source for logo.webp, favicon.png and the social card. The complete mark is preserved. The supplied PNG is the visual source of truth where the PDF's references to a botanical logo differ. This project uses a light header because only the light logo artwork was supplied. A dedicated approved small icon is recommended for a clearer favicon.

Design colours and tone come from `NOHA_HANNAH_Complete_Brand_Guide(1).pdf`. Georgia and a system sans serif are used as the guide's permitted fallback fonts, so the site has no external font dependency.
